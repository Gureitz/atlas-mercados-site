## Ponte até o lucro — estrutura do modelo

|  |  |  |
|---|---|---|
|  | Receita líquida | ponto de partida |
| − | Custo dos produtos/serviços | us-gaap CostOfRevenue |
| = | Lucro bruto | GrossProfit |
| − | Despesas operacionais | não decomposto no XBRL básico |
| = | EBIT | OperatingIncomeLoss |
| + | Resultado financeiro e outros |  |
| − | Imposto de renda |  |
| = | Lucro líquido | NetIncomeLoss / ProfitLoss |
